# Mahin Naveen — Personal Website

EE461L Homework 4, Task 1. A single-page personal website built with HTML and an external CSS stylesheet, without JavaScript.

Live site: https://mintcode1.github.io/

## Files

- `index.html`: content, section divs, external links, meta description, and image with alt text.
- `stylesheet.css`: tag selectors, shared classes, ID selectors, hover styles, margins, padding, and borders.
- `assets/workbench.svg`: original workbench illustration.

The `.interest` class is used three times. `#intro` is styled directly. The page includes `a:hover` styles and responsive layouts. GitHub Pages serves `main` from the repository root.
